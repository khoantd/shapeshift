# Learning pack — output templates

Use these section specs when writing a study pack from a video transcript. Include every section that has real substance; **omit rather than pad**. Match the language of the video/user.

## 1. Header & orientation

```markdown
# <Video title>

**Creator:** … · **Duration:** … · **Language:** …

### TL;DR
2–3 sentences.

### Who this is for
…

### What you'll be able to do after
Concrete outcome bullets.
```

## 2. Key concepts

3–10 ideas. Each:

```markdown
### <Concept name>
- **In plain words:** …
- **Why it matters:** …
- **Revisit:** [mm:ss]
```

## 3. Insights & takeaways

Non-obvious “so what” points — judgments, implications, connections (not a second concepts list).

## 4. Structured notes

Reorganize by theme (never a raw timestamp dump). Chunked subsections; keep numbers, names, worked examples the speaker gave.

## 5. Glossary

One-line definitions. Skip if none.

## 6. Worked example / walkthrough **or** Key arguments

- **Tutorial** → steps / checklist / commands / code (paraphrased, not long dumps)
- **Talk** → thesis + evidence structure
- **Documentary** → timeline / actors
- **Review** → claims vs evidence + verdict
- **Lecture** → concept map or cause–effect chain

## 7. Check your understanding

5–10 questions spanning recall → apply → analyze. Then an **Answer key** below (separate so learners can test first).

## 8. Flashcards

8–20 atomic Q/A pairs. Prefer a list:

```markdown
- Q: … | A: …
```

## 9. Apply it

Mini-exercise or reflection prompts.

## 10. Go deeper

Next topics / search terms. Only include URLs you can verify; otherwise suggest search terms.

## Quality bar

- Explain in your own words; short attributed quotes only.
- Anchor concepts to `[mm:ss]` when the transcript has timestamps.
- Never invent content not in the transcript; flag contested claims.
- Scale depth to video length (Short → tight one-pager; long lecture → multi-module).
