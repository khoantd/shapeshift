## 2. What the Add-on does

The Add-on helps you use Meanbox while browsing, including (as enabled by you and by permissions you grant):

- GitHub repository lens (summaries, related content, published security advisories where available);
- YouTube study companion and learning-pack flows via the Service;
- in-sidebar news / lesson deep dive and related tools;
- Quick Gadgets (for example tip, split, convert, timer, RTCFC) and Places deep links;
- toolbar popup, sidebar, omnibox (`mb`), and context-menu actions.

The Add-on is a **client** that talks to the Meanbox Service (default API base `https://meanbox.vercel.app`, or another base you configure in Options). Features that need a signed-in Meanbox account only work when you are signed in on that API base.
