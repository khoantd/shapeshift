Meanbox options

Production default is https://meanbox.vercel.app. Use http://localhost:3000 while developing the web app.

Device history: learning packs, summaries, deep dives, and gadgets are stored in this browser when you are not signed in.

Firefox asks you to allow host access per site. Grant Meanbox + GitHub + YouTube, and any news or e-learning sites you want deep dive on, so the sidebar can extract titles and call the API.
